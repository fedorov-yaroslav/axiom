# Метод первых принципов: Карта декомпозиции задач

MVP-приложение, помогающее применять **First Principles (Метод первых принципов)** для глубокого анализа и декомпозиции сложных задач. Это фундаментальный подход, который используют физики, инженеры и изобретатели (включая Илона Маска) для поиска неочевидных решений.

### Как это работает:
* **Интерактивный опрос:** Пользователь пошагово отвечает на 10 сильных вопросов, касающихся его проблемы (отделение стереотипов от ограничений, поведение на бесконечности, паразитные затраты энергии).
* **Стресс-тест логики:** Программа заставляет переводить абстрактные чувства в строгие физические величины и метрики.
* **Готовое ТЗ на выходе:** В финале формируется структурированная карта декомпозиции, которую можно в один клик распечатать или сохранить как PDF-файл.

### Технологический стек:
* React + TypeScript + Vite
* Custom Hooks (архитектурное разделение логики и UI)
* LocalStorage (автоматическое сохранение прогресса сессии)
* Нативные CSS @media print-шаблоны
